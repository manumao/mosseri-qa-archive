# Mosseri Q&A Archive

An unofficial, searchable archive of Adam Mosseri's Instagram Story Q&As.

Every week Adam Mosseri, the head of Instagram, answers questions from creators and users in his Instagram Stories. Stories disappear after 24 hours, so this site keeps a plain-language summary of each answer and links to the exact moment in the video on YouTube.

**Live site:** https://manumao.github.io/mosseri-qa-archive/

## What's on the site

- A short summary of every answer, grouped by Q&A session
- Topic tags (Reels & video, Features, Reach, Apps, Company, Policy) and a topic filter
- A "Watch at m:ss" link for each answer that opens the YouTube video at that second
- Light and dark mode, and a layout that works on desktop and mobile

## How it's built

It's a single `index.html` with inline CSS and JavaScript. There's no build step or framework, and GitHub Pages serves it straight from the `main` branch.

## Disclaimer

This project isn't affiliated with Instagram or Meta. The summaries are paraphrased, not exact quotes. The original Stories come from [@mosseri](https://www.instagram.com/mosseri/).
